🌍 [EO Analytics group](https://www.plus.ac.at/geoinformatik/research/eo-analytics/?lang=en), Department of Geoinformatics - Z_GIS, University of Salzburg 
&
🌍 [Professorship of Earth Observation for Ecosystem Management](https://www.lss.ls.tum.de/en/eoem/start/), Technical University of Munich

My research lies at the intersection of (ecological) remote sensing, spatial statistics, and machine learning, with a particular interest in representation learning, spatial and temporal inference, and the integration of data-driven methods with domain knowledge.

I am especially interested in understanding what information we can extract from Earth observation data, how reliable and transferable our methods are, and how we can use them to address ecological and environmental questions.

### 🧠 Programming languages & tools I like to use

🐍 **Python**  
I use Python for large-scale Earth observation workflows, such as handling raster time series (`xarray`, `rioxarray`), training machine learning models (`scikit learn`, `keras`) and accessing APIs like Google Earth Engine.

📓 **Jupyter Notebooks**  
My go-to environment for interactive, reproducible research. Ideal for teaching, prototyping models, visualizing spatial-temporal trends, and communicating insights in both Python and R.

📊 **R**  
Used for statistical modeling, especially GAMs and mixed-effects models via `mgcv` and `nlme`, as well as publication-ready figures using `ggplot2`. I also use R for geospatial workflows (`terra`, `sf`) for ecological applications.

🐚 **Bash / Shell scripting**  
Efficient for automation, high-performance computing, and batch processing of satellite imagery. I particularly use command-line tools such as GDAL for reprojection, format conversion, and tiling.

🚀 **FORCE**  
A powerful, open-source framework for generating analysis-ready data cubes and computing spectral-temporal metrics at scale. I use FORCE to preprocess and analyze multi-decadal Landsat and Sentinel-2 time series.
